# Silk — SilkSat + SilkHeat (VST3, estética D.T.H.)

## SilkSat (suavizador de voces)
Saturación 4x + anti-filo dinámico. Novedad: botón **ESCUCHAR FILO** (solo se oye la zona que trabaja el anti-filo:
mueve ZONA FILO hasta oír dónde molesta la voz y deja ahí el control).

## SilkHeat (calor tipo HEAT)
Drive de -5 a +5 y Tone de -3 a +3, **con "clicks"** como el original. Botón PRESET: Drive -2 / Tone +2.

## Compilar sin instalar nada
Sube el contenido de esta carpeta a tu repositorio de GitHub (reemplaza los archivos), mantén
.github/workflows/build.yml, y descarga "SilkVST3-Windows" desde Actions.
